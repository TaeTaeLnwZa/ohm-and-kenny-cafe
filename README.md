# Ohm & Kenny Cafe

A responsive one-page fictional cafe website built with plain HTML and CSS for a student assignment. Olive-green theme, cafe menu, opening hours, location, and contact section.

## Run locally

```sh
python3 -m http.server 8000
```

Open http://localhost:8000.

## Deploy to Vercel

Import this repository, select **Other** as the framework, leave the build command blank, and serve the repository root. No environment variables or build dependencies are required.

## Content and privacy

All cafe details are fictional. The `.example` email address is intentionally non-operational. No real contact details, API keys, credentials, or personal data are included. Local credentials and deployment settings are excluded through `.gitignore`.
